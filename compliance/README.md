# Compliance Framework Implementations

Governance artifacts mapped to regulatory frameworks for regulated industries: financial services, healthcare, legal, and enterprise.

Each subfolder contains workflows, prompt templates, and governance documents built against the named framework. Artifacts are production-ready and importable into any n8n instance.
